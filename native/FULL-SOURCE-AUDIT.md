## Backlog reconciliation

The source audit exposed omissions from the previous checklist: authenticated recent-game sync, per-game server history/exact rejoin, history clear, launch shortcut export, flag row/selection actions, mod image previews/size summaries, onboarding and explicit acceptance of the manual-cookie, discovery/quit and developer-harness differences. These are added to the master checklist rather than being counted complete.

The public experience browser implements explicit keyword searches, pagination, save, website opening and launch through the existing launch pipeline. It is neither a personalized Roblox home feed nor a parental-control replacement. The public endpoint is identified in [Roblox's official endpoint migration announcement](https://devforum.roblox.com/t/official-list-of-deprecated-web-endpoints/62889/59); an unauthenticated response was checked during implementation. Its schema and availability remain external dependencies.

Portable settings backups cover validated preferences, active palette, profiles (including disabled flags) and saved-game assignments. They omit account/session material and machine-local resource libraries. Restore preserves local account/mod records and installation selection, disables imported automation, refuses stale reviews and saves the previous configuration before replacement. Full resource/library migration is outside this implemented settings-only format and remains an explicit scope decision.

No source-audit completion checkbox certifies live Roblox, Discord, notifications, display recovery, account switching or minimum-OS/Intel behavior.
