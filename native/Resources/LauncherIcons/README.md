# Original AppleBlox launcher icons

These GPL-3.0 assets are copied from the inherited AppleBlox source retained in this repository:

- Original.icns: legacy/scripts/build/assets/mac.icns
- dark.icns, clear_light.icns, clear_dark.icns, tinted_light.icns and tinted_dark.icns: legacy/scripts/build/assets/bundled-icons/

Original AppleBlox logo credit: @typeofnull, as credited by upstream AppleBlox. See the root LICENSE and docs/LEGACY.md. These are explicitly labelled original styles in the native Dock-icon library. The default fork icon is generated separately from native geometry and retains the fork’s blue leaf.

Native builds use these copies and never read legacy/.
